# رَوَند — سامانهٔ حضور و غیاب

رابط فارسی و راست‌چین برای مدیریت کارکنان، ثبت وضعیت حضور، دورهٔ حقوق، و گزارش‌گیری. این مخزن از ابتدا با Next.js ساخته شده است؛ رابط فعلی **حالت نمایشی** دارد و داده‌های آزمایشی را فقط در مرورگر ذخیره می‌کند. هنوز به Supabase یا سرویس احراز هویت وصل نشده و استفادهٔ عملیاتی یا چندکاربره نیازمند تکمیل اتصال سمت سرور است.

## اجرا

```bash
npm install
npm run dev
```

باز کردن http://localhost:3000 . ورود نمایشی مدیر: `admin` / `admin`. این رمز فقط برای پیش‌نمایش محلی است و نباید در استقرار عمومی استفاده شود.

## آماده‌سازی برای Vercel

1. یک پروژهٔ Supabase بسازید و `supabase/schema.sql` را در SQL Editor اجرا کنید.
2. از `.env.example` یک `.env.local` بسازید و آدرس و کلید عمومی Supabase را وارد کنید.
3. یک کاربر در Supabase Auth بسازید و پروفایل او را با نقش `admin` از محیط امن SQL تنظیم کنید.
4. در Vercel همین متغیرها را در تنظیمات پروژه تعریف و مخزن را متصل کنید.

اتصال داده‌ها، ایجاد حساب از سرور با نقش مجاز، احراز هویت TOTP، ثبت تراکنش‌های حضور، بستن خودکار شیفت در نیمه‌شب به وقت تهران، محاسبهٔ بازه‌های جلالی و ذخیرهٔ تنظیمات، باید پیش از استفادهٔ واقعی به APIهای سمت سرور متصل شوند. `schema.sql` ساختار اولیه و سیاست‌های RLS را فراهم می‌کند. Google Authenticator با ثبت ایمیل Google کار نمی‌کند؛ هر کاربر باید secret اختصاصی TOTP را از یک جریان امن دریافت و در برنامهٔ احراز هویت خود ثبت کند.

## قابلیت‌های رابط فعلی

- داشبورد فارسی با وضعیت حضور، نمودار کارکرد، جستجو و جدول کارکنان
- افزودن کارمند نمایشی، ثبت ورود/خروج/مرخصی و ذخیرهٔ محلی مرورگر
- پنج تم رنگی، تنظیم نام مجموعه، تنظیم دوره و خروجی CSV سازگار با Excel
- صفحهٔ ورود آزمایشی جدا از عملیات کارکنان و طرح واکنش‌گرا

گزارش فعلاً CSV است تا با Excel باز شود؛ تولید فایل XLSX واقعی و نقش‌های حسابدار/دستیار هنوز به سرویس داده وصل نشده‌اند.
